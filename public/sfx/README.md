# Optional recorded cheers

Drop `cheer-big.mp3` and `cheer-small.mp3` here (any format the browser can
decode) and they play under the hole-in-one and birdie stingers. Missing
files are skipped silently; the game ships without them.

## hook-vocal.wav

The "PUTT PUTT POT-TY" chant that plays over the hook bars of the theme
(bars 1, 3, 5 and 7). It is cut to the hook rhythm at 118 BPM: "putt" on
beat 1, "putt" on beat 2, "potty" on beat 3, about 1.6 s long. Replace it
with a real recording (any format the browser decodes, keep the timing)
and the theme picks it up. Delete it and the theme plays without words.
